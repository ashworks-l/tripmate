# TripMate – Design Planning

## 1. Design Overview

TripMate has a clean, modern, and welcoming design. The application uses natural colors, rounded elements, soft shadows, and simple navigation to make travel planning easy and enjoyable.

## 2. Color Palette

The main colors currently used in the application are:

| Color | Hex Code | Purpose |
|---|---|---|
| Primary Green | #526e57 | Main buttons and sections |
| Soft Green | #7b9b78 | Highlights and accents |
| Cream Background | #faf9f6 | Main page background |
| Dark Green | #24352e | Main text |
| Light Gray | #e9e8e2 | Borders and separators |
| Secondary Gray | #89938b | Secondary text |
| Muted Green | #65746a | Navigation text |

## 3. Typography

The project imports Geist Sans and Geist Mono using Next.js font configuration.

Currently, the global body style uses Arial, Helvetica, and sans-serif as its font family.

The design uses large bold headings, readable paragraphs, and different font sizes to establish visual hierarchy.

## 4. Layout and Spacing

The application follows these layout conventions:

- Centered content with a maximum width of 7xl.
- Consistent horizontal padding using px-6.
- Generous vertical spacing between sections.
- Rounded cards and buttons.
- Soft shadows and subtle hover effects.
- Grid layouts for destinations and features.
- Flexible layouts using Flexbox.

## 5. Responsive Design

Tailwind CSS responsive utilities are used to adapt the application to different screen sizes.

- Mobile: vertically organized content and simplified navigation.
- Tablet: flexible layouts and adjusted spacing.
- Desktop: two-column hero section and multi-column card layouts.

The application uses the sm and md responsive breakpoints.

## 6. Main UI Components

The current homepage includes:

- Header and navigation.
- Hero section.
- Destination cards.
- Feature cards.
- About section.
- Footer.
- Reusable buttons and links.

## 7. Technologies

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## 8. Design Goals

1. Make travel planning simple and intuitive.
2. Provide a consistent visual experience.
3. Support different screen sizes.
4. Maintain reusable UI patterns.
5. Create a welcoming visual identity inspired by travel and nature.
